## 实现步骤

### Step 1: 扩展 CustomTable 属性

修改 [CustomTable.ts](e:/job-project/collabedit-fe/src/views/template/editor/extensions/CustomTable.ts)：

```typescript
export const CustomTable = Table.extend({
  addAttributes() {
    return {
      ...this.parent?.(),
      style: { /* 已有 */ },
      allowBreakAcrossPages: {
        default: true,
        parseHTML: el => el.getAttribute('data-break-across') !== 'false',
        renderHTML: attrs => attrs.allowBreakAcrossPages === false
          ? { 'data-break-across': 'false' } : {}
      },
      repeatHeaderRow: {
        default: false,
        parseHTML: el => el.getAttribute('data-repeat-header') === 'true',
        renderHTML: attrs => attrs.repeatHeaderRow
          ? { 'data-repeat-header': 'true' } : {}
      },
      tableCaption: {
        default: null,
        parseHTML: el => el.getAttribute('data-caption'),
        renderHTML: attrs => attrs.tableCaption
          ? { 'data-caption': attrs.tableCaption } : {}
      },
      tableCaptionPosition: {
        default: 'before',
        parseHTML: el => el.getAttribute('data-caption-pos') || 'before',
        renderHTML: attrs => attrs.tableCaptionPosition !== 'before'
          ? { 'data-caption-pos': attrs.tableCaptionPosition } : {}
      },
    }
  },
  // renderHTML 已有
})
```

### Step 2: 扩展 CustomTableCell 属性

修改 [CustomTableCell.ts](e:/job-project/collabedit-fe/src/views/template/editor/extensions/CustomTableCell.ts)：

```typescript
// 在 addAttributes 中新增
cellFontFamily: {
  default: null,
  parseHTML: el => el.getAttribute('data-font-family'),
  renderHTML: attrs => {
    if (!attrs.cellFontFamily) return {}
    return { 'data-font-family': attrs.cellFontFamily, style: `font-family: ${attrs.cellFontFamily}` }
  }
},
cellLineHeight: {
  default: null,
  parseHTML: el => el.getAttribute('data-line-height'),
  renderHTML: attrs => {
    if (!attrs.cellLineHeight) return {}
    return { 'data-line-height': attrs.cellLineHeight, style: `line-height: ${attrs.cellLineHeight}` }
  }
},
```

## 风险评估

| 风险 | 措施 |
|------|------|
| 新属性影响现有表格 | 默认值 true/false/null 保持现有行为 |
| data-* 属性丢失 | 使用 parseHTML/renderHTML 持久化到 DOM |
