# P1-2: 强大的样式刷

> **优先级**: P1 | **预估工期**: 3天 | **前置依赖**: P0-0（字体/段落格式基础）

## 目标

不仅复制文字格式（粗体/斜体/颜色/字体/字号），还能复制段落格式（大纲级别、行距、首行缩进）。支持单次刷和锁定刷。

## 现有可复用

演训编辑器 `StartToolbar.vue` 已有格式刷功能，可参考其交互逻辑。

## 实现步骤

### Step 1: FormatPainter 扩展

新增 `src/shared/extensions/FormatPainter.ts`：

```typescript
import { Extension } from '@tiptap/core'

interface StoredFormat {
  marks: { type: string; attrs: Record<string, any> }[]
  nodeAttrs: Record<string, any>  // paragraph/heading 级属性
}

export const FormatPainter = Extension.create({
  name: 'formatPainter',
  addStorage() {
    return { storedFormat: null as StoredFormat | null, mode: 'off' as 'off' | 'single' | 'locked' }
  },
  addCommands() {
    return {
      startFormatPainting: () => ({ editor }) => {
        // 读取当前选区的 marks 和节点属性
        const { from, to } = editor.state.selection
        const marks = editor.state.doc.resolve(from).marks().map(m => ({ type: m.type.name, attrs: m.attrs }))
        const node = editor.state.doc.resolve(from).parent
        const nodeAttrs = { ...node.attrs }  // textAlign, lineHeight, firstLineIndent 等
        this.storage.storedFormat = { marks, nodeAttrs }
        this.storage.mode = 'single'
        return true
      },
      lockFormatPainting: () => ({ editor }) => {
        // 与 startFormatPainting 相同，但 mode 为 locked
        // ...同上逻辑
        this.storage.mode = 'locked'
        return true
      },
      applyFormatPainting: () => ({ editor, chain }) => {
        if (!this.storage.storedFormat) return false
        const { marks, nodeAttrs } = this.storage.storedFormat
        const { from, to } = editor.state.selection
        // 清除现有 marks
        let c = chain().focus()
        c = c.unsetAllMarks()
        // 应用存储的 marks
        for (const mark of marks) { c = c.setMark(mark.type, mark.attrs) }
        // 应用节点属性
        c = c.updateAttributes(editor.state.doc.resolve(from).parent.type.name, nodeAttrs)
        c.run()
        if (this.storage.mode === 'single') {
          this.storage.storedFormat = null
          this.storage.mode = 'off'
        }
        return true
      },
      stopFormatPainting: () => () => {
        this.storage.storedFormat = null
        this.storage.mode = 'off'
        return true
      },
    }
  },
})
```

### Step 2: 工具栏按钮

修改 [MarkdownEditor.vue](e:/job-project/collabedit-fe/src/views/template/editor/components/MarkdownEditor.vue) 工具栏：

```html
<button
  class="toolbar-btn"
  :class="{ active: formatPainterMode !== 'off' }"
  @click="handleFormatPainterClick"
  @dblclick="handleFormatPainterDblClick"
  title="格式刷（单击=单次，双击=锁定）"
>
  <Icon icon="mdi:format-paint" />
</button>
```

```typescript
const formatPainterMode = computed(() => editor.value?.storage.formatPainter?.mode || 'off')

const handleFormatPainterClick = () => {
  if (formatPainterMode.value !== 'off') {
    editor.value?.commands.stopFormatPainting()
  } else {
    editor.value?.commands.startFormatPainting()
  }
}

const handleFormatPainterDblClick = () => {
  editor.value?.commands.lockFormatPainting()
}
```

### Step 3: 鼠标光标切换

格式刷激活时切换鼠标样式：
```css
.ProseMirror.format-painting {
  cursor: url('data:image/svg+xml,...') 0 16, crosshair;  /* 刷子图标 */
}
```

通过监听 `formatPainterMode` 在 ProseMirror DOM 上添加/移除 class。

### Step 4: 选区后自动应用

在 `FormatPainter` 扩展中添加 ProseMirror Plugin 监听 selectionchange：
- 格式刷激活时，用户选择新文本后自动调用 `applyFormatPainting`
- 单次模式应用后自动退出
- 锁定模式持续应用，按 ESC 退出
