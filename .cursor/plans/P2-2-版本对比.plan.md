# P2-2: 版本对比

> **优先级**: P2 | **预估工期**: 8天 | **前置依赖**: P0-6（DOCX导出/保存）

## 目标

高亮显示两个版本文档之间的差异（文字、表格、图片的增删改）。

## 实现步骤

### Step 1: 后端 DocumentVersion 模型

新增 Prisma 模型：
```prisma
model DocumentVersion {
  id          String   @id @default(uuid())
  documentId  String
  version     Int
  content     Json     // HTML 快照
  fileId      String?  // MinIO 快照文件（可选）
  userId      Int
  userName    String
  description String?
  createdAt   DateTime @default(now())
  @@index([documentId, version])
}
```

### Step 2: 后端 API

新增 `src/routes/documentVersion.ts`：
- `POST /api/documentVersion/create` -- 创建版本快照
- `GET /api/documentVersion/list?documentId=` -- 版本列表
- `GET /api/documentVersion/detail/:id` -- 获取版本内容
- `POST /api/documentVersion/compare` -- 对比两个版本（body: { versionId1, versionId2 }）

自动快照：每次 `saveFile` 时自动创建版本记录。

### Step 3: 前端 VersionCompare 组件

新增 `src/views/template/editor/components/VersionCompare.vue`：
- el-dialog 全屏弹窗
- 左侧：版本列表（时间 + 用户 + 描述）
- 右侧：差异视图（左右分栏或合并视图）
- 使用 `diff-match-patch` 库对比 HTML 文本差异
- 差异高亮：绿色背景=新增、红色背景=删除、黄色背景=修改
- 支持恢复到指定版本

### Step 4: 中间件可选增强

在中间件 gateway 中定时（如每 30 分钟）从 Y.Doc 导出 HTML 快照发送到后端存储。
