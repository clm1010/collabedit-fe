# P2-5: 文档属性检查

> **优先级**: P2 | **预估工期**: 3天 | **前置依赖**: P0-0

## 目标

在文档导出前检测并清除隐藏的个人信息、元数据、图片 EXIF 数据等，确保文档安全性。

## 实现步骤

### Step 1: MetadataInspector 组件

新增 `src/views/template/editor/components/MetadataInspector.vue`：

el-dialog 弹窗，检测项目：

1. **HTML 注释**：检测文档内容中的 `<!-- ... -->` 标签
2. **隐藏 span**：检测 `display:none`、`visibility:hidden`、`font-size:0` 等不可见文本
3. **图片 EXIF 数据**：检测 `<img>` 的原始文件中的 GPS、设备信息（需用 canvas 读取或前端 EXIF 库）
4. **批注中的个人信息**：列出所有批注的用户名
5. **修订中的个人信息**：列出所有修订记录的用户名
6. **文档元数据**：documentMeta Y.Map 中的信息

每项检测结果以列表展示，可选择性清除。

### Step 2: 一键清除

- "清除所有"按钮
- 移除 HTML 注释
- 移除隐藏元素
- 清理图片 EXIF（canvas 重绘后重新上传）
- 清除批注/修订（可选，需确认）

### Step 3: 导出时自动检查

在 `wordExport.ts` 的导出流程中：
- 导出前自动执行清理（HTML 注释移除、隐藏元素移除）
- 弹窗提示用户确认是否需要清理个人信息

### Step 4: 工具栏入口

修改 MarkdownEditor.vue 工具栏，在导出按钮旁添加"文档检查"按钮。
