# 行内图片文字底部对齐修复

## 问题分析

当前行内图片使用 `vertical-align: middle`，导致图片前后的文字垂直居中于图片。Umo Editor 的行内图片文字与图片底部对齐（`vertical-align: bottom`）。

需要修改 3 处 `vertical-align: middle` 为 `vertical-align: bottom`：

## 修改点

### 1. [ResizableImage.ts](e:/job-project/collabedit-fe/src/views/training/document/components/toolbar/extensions/ResizableImage.ts) 第 126 行

`display` 属性的 `renderHTML` 中：

```typescript
// 改前
return { 'data-display': 'inline', style: 'display: inline-block; vertical-align: middle;' }
// 改后
return { 'data-display': 'inline', style: 'display: inline-block; vertical-align: bottom;' }
```

### 2. [ResizableImageComponent.vue](e:/job-project/collabedit-fe/src/views/training/document/components/toolbar/extensions/ResizableImageComponent.vue) ~第 237 行

`wrapperStyle` 计算属性中行内模式的返回值：

```typescript
// 改前
return { display: 'inline-block', verticalAlign: 'middle', maxWidth: '100%' }
// 改后
return { display: 'inline-block', verticalAlign: 'bottom', maxWidth: '100%' }
```

### 3. [ResizableImageComponent.vue](e:/job-project/collabedit-fe/src/views/training/document/components/toolbar/extensions/ResizableImageComponent.vue) CSS `.is-inline` 规则

```scss
// 改前
vertical-align: middle;
// 改后
vertical-align: bottom;
```
