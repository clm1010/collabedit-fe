# P1-1: 修复演训编辑器图片拖拽调整与对齐 Bug

> **优先级**: P1 | **预估工期**: 2天 | **前置依赖**: 无

## Bug 现象

1. **编辑器中拖拽调整图片大小无效**：拖动 resize 手柄后图片视觉上不变
2. **但预览中图片大小已改变**：点击"文档预览"后发现图片确实被缩小了
3. **图片对齐在预览中不生效**：编辑器中对齐正常，预览中对齐失效

参考截图：

- [img2.jpg](C:/Users/limin/Desktop/参考图/fix-img2/img2.jpg) -- 编辑器中图片看起来未被调整
- [img3.jpg](C:/Users/limin/Desktop/参考图/fix-img2/img3.jpg) -- 预览中图片尺寸实际已变小

## 根因分析

### Bug 1: 编辑器中拖拽调整大小无效

**根因**：`ResizableImageComponent.vue` 的 `imageStyle` 计算属性（第 249-257 行）始终返回 `width: 'auto', height: 'auto'`，**从未使用 `node.attrs.width` 和 `node.attrs.height`**。

```249:257:e:/job-project/collabedit-fe/src/views/training/document/components/toolbar/extensions/ResizableImageComponent.vue
const imageStyle = computed(() => {
  return {
    maxWidth: `${editorMaxWidth.value}px`,
    width: 'auto',        // <-- BUG: 始终 auto，忽略 node.attrs.width
    height: 'auto',       // <-- BUG: 始终 auto，忽略 node.attrs.height
    display: imageError.value ? 'none' : 'block'
  }
})
```

同时，`handleResize` 在拖拽过程中更新了 `currentWidth.value` / `currentHeight.value`，但这两个值也没有参与 `imageStyle` 的计算，所以拖拽过程中也没有视觉反馈。

`stopResize`（第 588-599 行）正确地将 `currentWidth` / `currentHeight` 通过 `updateAttributes` 写入了节点属性，所以 `getHTML()` 序列化的 HTML 有正确的 `width`/`height`，预览因此显示正确。

**数据流断裂**：

```
拖拽手柄 → handleResize → currentWidth/currentHeight 更新
                                     ↓ (写入节点)
                          stopResize → updateAttributes({ width, height })
                                     ↓ (节点属性已更新)
                               node.attrs.width/height 有值
                                     ↓ (但 imageStyle 忽略了它)
                               imageStyle → width: 'auto' ← BUG
```

### Bug 2: CSS `height: auto !important` 覆盖

即使修复了 `imageStyle`，组件内 scoped CSS（第 516-524 行附近）有：

```css
img {
  height: auto !important; /* <-- 会覆盖 inline style 的 height */
}
```

这会导致通过 style 设置的固定 height 被覆盖。

### Bug 3: 预览中对齐不生效

`ResizableImage.ts` 的 `renderHTML` 对 `align` 只输出 `data-align` 属性（第 106-110 行）：

```106:110:e:/job-project/collabedit-fe/src/views/training/document/components/toolbar/extensions/ResizableImage.ts
renderHTML: (attributes) => {
  return {
    'data-align': attributes.align
  }
}
```

但预览区域和 `TiptapEditor.vue` 的全局样式中**没有对 `data-align` 的 CSS 规则**，所以预览中图片始终按默认布局（块级左对齐），不管编辑器中设成了居中还是右对齐。

### Bug 4: 拖拽过程无视觉反馈

`handleResize` 更新 `currentWidth` / `currentHeight`，但没有任何元素的样式绑定这两个值。拖拽手柄时用户看不到图片在实时变化。

## 修复方案

### Fix 1: imageStyle 使用 node.attrs 和拖拽中的实时尺寸

修改 `ResizableImageComponent.vue` 第 249-257 行的 `imageStyle`：

```typescript
const imageStyle = computed(() => {
  const base: Record<string, string> = {
    maxWidth: `${editorMaxWidth.value}px`,
    display: imageError.value ? 'none' : 'block'
  }

  // 拖拽中：使用实时的 currentWidth/currentHeight
  if (isResizing.value) {
    base.width = `${currentWidth.value}px`
    base.height = `${currentHeight.value}px`
    return base
  }

  // 非拖拽：使用节点属性中保存的宽高
  const w = props.node.attrs.width
  const h = props.node.attrs.height
  if (w != null && w !== '' && w !== 0) {
    const parsedW = typeof w === 'number' ? w : parseFloat(String(w))
    if (!isNaN(parsedW) && parsedW > 0) {
      base.width = `${Math.min(parsedW, editorMaxWidth.value)}px`
    } else {
      base.width = 'auto'
    }
  } else {
    base.width = 'auto'
  }

  if (h != null && h !== '' && h !== 0) {
    const parsedH = typeof h === 'number' ? h : parseFloat(String(h))
    if (!isNaN(parsedH) && parsedH > 0) {
      base.height = `${parsedH}px`
    } else {
      base.height = 'auto'
    }
  } else {
    base.height = 'auto'
  }

  return base
})
```

**效果**：

- 拖拽过程中图片实时跟随鼠标缩放（视觉反馈）
- 拖拽结束后，`stopResize` 写入 `node.attrs`，`imageStyle` 读取并显示正确尺寸
- 无 width/height 属性时（新图片），保持 `auto` 行为不变

### Fix 2: 移除 `height: auto !important` CSS

修改 `ResizableImageComponent.vue` scoped CSS 中的 `img` 样式：

**修改前**（约第 516-524 行附近）：

```css
img {
  border-radius: 4px;
  cursor: default;
  user-select: none;
  display: block !important;
  height: auto !important; /* <-- 删除此行 */
  max-height: none !important;
}
```

**修改后**：

```css
img {
  border-radius: 4px;
  cursor: default;
  user-select: none;
  display: block !important;
  max-height: none !important;
  /* height 由 imageStyle 动态控制，不再强制 auto */
}
```

### Fix 3: 预览区域添加 data-align 对齐 CSS

修改 [TiptapEditor.vue](e:/job-project/collabedit-fe/src/views/training/document/components/TiptapEditor.vue)，在预览和编辑器全局样式中添加：

```css
/* 图片对齐 -- 用于预览和导出 */
img[data-align='center'] {
  display: block;
  margin-left: auto;
  margin-right: auto;
}
img[data-align='left'] {
  display: block;
  margin-right: auto;
  margin-left: 0;
}
img[data-align='right'] {
  display: block;
  margin-left: auto;
  margin-right: 0;
}
```

同时检查 `renderHTML` 中是否还需要输出 `style` 属性（当前只输出 `data-align`，建议同时输出 inline style 作为兜底，确保在任何无 CSS 环境下也能对齐）。

修改 `ResizableImage.ts` 第 101-111 行的 `align` 的 `renderHTML`：

```typescript
align: {
  default: 'center',
  parseHTML: (element) => element.getAttribute('data-align') || 'center',
  renderHTML: (attributes) => {
    const align = attributes.align || 'center'
    let style = 'display: block;'
    if (align === 'center') style += ' margin-left: auto; margin-right: auto;'
    else if (align === 'right') style += ' margin-left: auto; margin-right: 0;'
    else style += ' margin-right: auto; margin-left: 0;'
    return { 'data-align': align, style }
  },
},
```

这样预览和导出的 HTML 中图片自带对齐样式，不依赖外部 CSS。

### Fix 4: 拖拽时显示尺寸提示

在 `ResizableImageComponent.vue` 的模板中，resize 手柄区域内添加尺寸提示（如果尚未存在）：

```html
<div v-if="isResizing" class="size-tooltip">
  {{ Math.round(currentWidth) }} × {{ Math.round(currentHeight) }}
</div>
```

```css

```

## 风险评估

| 风险 | 影响 | 措施 |
| --- | --- | --- |
| 移除 `height: auto !important` 后极端比例图片可能变形 | 部分图片显示异常 | imageStyle 中已有 maxWidth 限制；height 仅在有值时设置，无值时仍为 auto |
| 已有文档中图片无 width/height 属性 | 不影响，imageStyle 返回 auto 与当前行为一致 |  |
| inline style 优先级覆盖外部 CSS | align 的 inline style 可能与其他样式冲突 | data-align 和 inline style 双保险，CSS 作为 fallback |
| 协同编辑时 width/height 变更同步 | updateAttributes 产生 Transaction，Y.js 自动同步 | 已有机制，无需额外处理 |

## 验收标准

- 在演训编辑器中拖拽 resize 手柄，图片实时跟随鼠标变化大小
- 拖拽过程中显示尺寸提示（如 "320 × 240"）
- 拖拽结束后图片保持调整后的尺寸
- 按 Shift 拖拽时锁定宽高比
- 点击对齐按钮（左/中/右）在编辑器中正确对齐
- 点击"文档预览"后图片尺寸与编辑器中一致
- 点击"文档预览"后图片对齐与编辑器中一致
- 导出的文档中图片尺寸和对齐正确
- 关闭文档重新打开后图片尺寸和对齐保持
- 协同编辑时图片尺寸调整在另一端实时同步
- 无 width/height 属性的旧图片不受影响（仍按自然尺寸显示）
- 图片错误处理（加载失败/重试）不受影响
