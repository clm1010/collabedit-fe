# P0-5: 目录与图表索引

> **优先级**: P0 | **预估工期**: 8天 | **前置依赖**: P0-2（标题+自动编号）

## 目标

一键生成和更新文档目录、图索引、表索引。格式：`图1 XXX`、`表1 XXX`。

## 实现步骤

### Step 1: FigureCaption 扩展

新增 `src/shared/extensions/FigureCaption.ts`：
- 自定义块级 wrapper 节点 `figure`，包含 image 子节点 + figcaption 子节点
- 属性：`captionText`（标题文本）、`figureId`（唯一标识，用于交叉引用）
- 编号通过 Decoration 自动计算（遍历文档中所有 figure 节点，按顺序编号）
- NodeView 渲染：图片 + 下方居中的"图X 标题文本"

### Step 2: TableCaption 扩展

新增 `src/shared/extensions/TableCaption.ts`：
- 类似 FigureCaption，但与 table 节点关联
- 可直接复用 P0-4 中 CustomTable 的 `tableCaption` 属性
- 编号独立于图编号（表1, 表2, 表3...）

### Step 3: TableOfContents 扩展

新增 `src/shared/extensions/TableOfContents.ts`：
- 自定义块级节点 `tableOfContents`
- NodeView 组件 `TableOfContentsComponent.vue`：
  - 监听编辑器 `update` 事件
  - 遍历所有 heading 节点，读取 AutoNumbering 的编号
  - 生成目录列表：`1 引言 ......... (页码仅导出时)`
  - 点击条目调用 `editor.commands.focus()` + `scrollIntoView` 跳转
  - 可折叠/展开二级目录
  - 灰色边框区分于正文

### Step 4: IndexBlock 扩展

新增 `src/shared/extensions/IndexBlock.ts`：
- 自定义块级节点 `indexBlock`
- 属性：`indexType`（'figure' | 'table'）
- NodeView 组件 `IndexBlockComponent.vue`：
  - 遍历文档中所有 FigureCaption / TableCaption 节点
  - 生成索引列表：`图1 XXX`、`表1 XXX`
  - 点击跳转到对应图/表

### Step 5: 工具栏集成

修改 [MarkdownEditor.vue](e:/job-project/collabedit-fe/src/views/template/editor/components/MarkdownEditor.vue) 工具栏，新增"插入"下拉菜单：

```html
<el-dropdown trigger="click" @command="handleInsertCommand">
  <button class="toolbar-btn" title="插入">
    <Icon icon="mdi:plus-box" />
    <Icon icon="mdi:chevron-down" class="ml-0.5 text-xs" />
  </button>
  <template #dropdown>
    <el-dropdown-menu>
      <el-dropdown-item command="toc">插入目录</el-dropdown-item>
      <el-dropdown-item command="figureIndex">插入图索引</el-dropdown-item>
      <el-dropdown-item command="tableIndex">插入表索引</el-dropdown-item>
      <el-dropdown-item divided command="figureCaption">添加图标题</el-dropdown-item>
      <el-dropdown-item command="tableCaption">添加表标题</el-dropdown-item>
    </el-dropdown-menu>
  </template>
</el-dropdown>
```

### Step 6: Markdown 兼容

- 目录导出：`[TOC]`
- 图标题导出：保留 `<figure>` HTML 标签或 `![标题](url "图X 标题")`
- 表标题导出：`<!-- TABLE_CAPTION: 表X 标题 -->`
- 索引块导出：`<!-- FIGURE_INDEX -->` / `<!-- TABLE_INDEX -->`

### Step 7: Word 导出适配（依赖 P0-6）

- 目录：使用 `docx` 库的 `TableOfContents` 类生成 TOC 域
- 图标题：使用 `docx` 的 Caption 段落样式
- 表标题：同上
- 索引：导出时根据实际编号动态生成
