# P1-3: 自动编号与交叉引用

> **优先级**: P1 | **预估工期**: 7天 | **前置依赖**: P0-2（AutoNumbering）, P0-5（FigureCaption/TableCaption）

## 目标

支持对"第X章"、"图X"、"表X"进行动态交叉引用。编号变化时引用自动更新。

## 实现步骤

### Step 1: CrossReference 扩展

新增 `src/shared/extensions/CrossReference.ts`：

- 自定义 inline 节点 `crossRef`
- 属性：`refType`（'heading' | 'figure' | 'table'）、`targetId`（目标唯一 ID）
- renderHTML：`<span data-type="cross-ref" data-ref-type="..." data-target-id="...">见图3</span>`
- ProseMirror Plugin：监听文档变化，遍历所有 crossRef 节点，根据 targetId 查找目标的当前编号，更新显示文本

### Step 2: 为可引用对象分配 ID

- heading 节点：通过 GjbHeading 扩展添加 `headingId` 属性（自动生成 UUID 或 `h-{index}`）
- figureCaption：已有 `figureId` 属性
- tableCaption：通过 CustomTable 的 `tableCaption` 属性关联

### Step 3: CrossReferenceDialog 组件

新增 `src/views/template/editor/components/CrossReferenceDialog.vue`：

- el-dialog 弹窗
- Tabs：标题引用 / 图引用 / 表引用
- 列出文档中所有可引用对象（编号 + 文本）
- 选择后插入 crossRef 节点
- 引用格式选择：`"见第X章"` / `"图X"` / `"表X"` / 自定义前缀

### Step 4: 工具栏按钮

修改 MarkdownEditor.vue 工具栏，新增"交叉引用"按钮。

### Step 5: Markdown 兼容

导出 Markdown 时 crossRef 渲染为纯文本（如"见图3"），导入时无法恢复引用关系。

## 涉及文件

**新增**：`src/shared/extensions/CrossReference.ts`, `src/views/template/editor/components/CrossReferenceDialog.vue`
**修改**：`src/shared/extensions/GjbHeading.ts`（添加 headingId）, [MarkdownEditor.vue](e:/job-project/collabedit-fe/src/views/template/editor/components/MarkdownEditor.vue)

## 验收标准

- [ ] 可通过弹窗插入对标题/图/表的交叉引用
- [ ] 引用文本显示正确编号（如"见图3"）
- [ ] 增删标题/图/表后，所有引用自动更新
- [ ] 点击引用可跳转到目标位置
- [ ] 协同编辑时引用在各端一致
