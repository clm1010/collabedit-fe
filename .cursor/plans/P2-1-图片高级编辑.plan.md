# P2-1: 图片高级编辑

> **优先级**: P2 | **预估工期**: 5天 | **前置依赖**: P1-1（ImageToolbar）

## 目标

调整亮度对比度、添加边框、压缩图片以减少文档体积。

## 实现步骤

### Step 1: 亮度/对比度

在 `ImageToolbar.vue` 中扩展，选中图片时显示：
- 亮度滑块（0-200%，默认100%）
- 对比度滑块（0-200%，默认100%）
- 应用 CSS filter：`filter: brightness(${v}%) contrast(${v}%)`
- 将 filter 值保存到 ResizableImage 的新属性 `imageFilter`

### Step 2: 边框样式

- 边框样式选择（无/实线/虚线/双线）
- 边框颜色选择器
- 边框粗细（1px-5px）
- 保存到 ResizableImage 的 `borderStyle` 属性

### Step 3: 图片压缩

- "压缩图片"按钮
- 使用 canvas 重绘：`canvas.toBlob(callback, 'image/jpeg', quality)`
- 压缩前后大小对比预览
- 压缩后重新上传到 MinIO 并替换 src

### Step 4: 扩展 ResizableImage 属性

在 `src/shared/extensions/image/ResizableImage.ts` 中 addAttributes 新增：
- `imageFilter`: string (default: null) -- CSS filter 值
- `borderStyle`: string (default: null) -- 边框样式

## 涉及文件

**修改**：`src/shared/extensions/image/ResizableImage.ts`, `ResizableImageComponent.vue`, `ImageToolbar.vue`

## 验收标准

- [ ] 可调整图片亮度和对比度
- [ ] 可为图片添加边框
- [ ] 可压缩图片并查看前后大小对比
- [ ] 压缩后图片重新上传到服务器
