# P2-3: 文档结构图导航

> **优先级**: P2 | **预估工期**: 4天 | **前置依赖**: P0-2（标题+自动编号）

## 目标

提供清晰的可视化文档结构（大纲），支持通过标题快速跳转。

## 实现步骤

### Step 1: DocumentOutline 组件

新增 `src/views/template/editor/components/DocumentOutline.vue`：

- 实时解析编辑器中的 heading 节点
- 生成树形结构（el-tree 或自定义）
- 显示自动编号 + 标题文本
- 缩进层级反映标题级别
- 点击跳转：`editor.commands.focus(pos)` + `scrollIntoView`
- 高亮当前可视区域对应的标题（IntersectionObserver）
- 折叠/展开层级

### Step 2: 集成到编辑器布局

修改 [MarkdownCollaborativeEditor.vue](e:/job-project/collabedit-fe/src/views/template/editor/MarkdownCollaborativeEditor.vue)：

在右侧面板（现有 CollaborationPanel）上方添加 Tab 切换：
- Tab 1：文档大纲
- Tab 2：协作者/要素（现有）

或者在左侧新增可折叠的大纲面板。

### Step 3: 实时更新

通过 `editor.on('update', ...)` 监听文档变化，debounce 200ms 后重新解析标题生成大纲。

## 涉及文件

**新增**：`src/views/template/editor/components/DocumentOutline.vue`
**修改**：[MarkdownCollaborativeEditor.vue](e:/job-project/collabedit-fe/src/views/template/editor/MarkdownCollaborativeEditor.vue)

## 验收标准

- [ ] 右侧面板可切换到文档大纲视图
- [ ] 大纲实时反映文档标题结构
- [ ] 显示自动编号
- [ ] 点击标题可跳转到对应位置
- [ ] 当前阅读位置在大纲中高亮
