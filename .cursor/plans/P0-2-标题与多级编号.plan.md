# P0-2: 标题与多级编号

> **优先级**: P0 | **预估工期**: 7天 | **前置依赖**: P0-0（字体扩展基础）

## 目标

标题1-5严格绑定字体（黑体）、字号、大纲级别，实现全自动多级编号（如 1, 1.1, 1.1.1）。

## 实现步骤

### Step 1: GjbHeading 扩展

新增 `src/shared/extensions/GjbHeading.ts`：

```typescript
import { Heading } from '@tiptap/extension-heading'

const GJB_HEADING_STYLES: Record<number, string> = {
  1: 'font-family: SimHei, 黑体, sans-serif; font-size: 18pt; font-weight: bold;', // 小二
  2: 'font-family: SimHei, 黑体, sans-serif; font-size: 16pt; font-weight: bold;', // 三号
  3: 'font-family: SimHei, 黑体, sans-serif; font-size: 14pt; font-weight: bold;', // 四号
  4: 'font-family: SimHei, 黑体, sans-serif; font-size: 12pt; font-weight: bold;', // 小四
  5: 'font-family: SimHei, 黑体, sans-serif; font-size: 10.5pt; font-weight: bold;' // 五号
}

export const GjbHeading = Heading.extend({
  addOptions() {
    return { ...this.parent?.(), levels: [1, 2, 3, 4, 5] }
  },
  addAttributes() {
    return {
      ...this.parent?.(),
      gjbStyle: { default: true } // 是否启用 GJB 样式绑定
    }
  },
  renderHTML({ node, HTMLAttributes }) {
    const level = node.attrs.level
    const gjbStyle = node.attrs.gjbStyle
    const style = gjbStyle ? GJB_HEADING_STYLES[level] || '' : ''
    return [
      `h${level}`,
      { ...HTMLAttributes, style: [HTMLAttributes.style, style].filter(Boolean).join('; ') },
      0
    ]
  }
})
```

**关键设计**：

- 节点名仍为 `heading`，与 StarterKit 兼容
- `gjbStyle` 属性默认 true，现有文档中无此属性时使用默认值 true 自动应用
- 若需自定义样式，可设为 false

### Step 2: AutoNumbering 扩展

新增 `src/shared/extensions/AutoNumbering.ts`：

```typescript
import { Extension } from '@tiptap/core'
import { Plugin, PluginKey } from '@tiptap/pm/state'
import { Decoration, DecorationSet } from '@tiptap/pm/view'

export const autoNumberingPluginKey = new PluginKey('autoNumbering')

function computeNumbering(doc) {
  const decorations: Decoration[] = []
  const counters = [0, 0, 0, 0, 0] // 5 levels

  doc.descendants((node, pos) => {
    if (node.type.name === 'heading') {
      const level = node.attrs.level // 1-5
      const idx = level - 1
      counters[idx]++
      // 重置下级计数器
      for (let i = idx + 1; i < 5; i++) counters[i] = 0
      // 生成编号文本
      const numberParts = counters.slice(0, level).filter((n) => n > 0)
      const numberText = numberParts.join('.') + ' '
      // 创建 widget decoration
      const widget = document.createElement('span')
      widget.className = 'auto-numbering'
      widget.textContent = numberText
      decorations.push(Decoration.widget(pos + 1, widget, { side: -1 }))
    }
  })
  return DecorationSet.create(doc, decorations)
}

export const AutoNumbering = Extension.create({
  name: 'autoNumbering',
  addProseMirrorPlugins() {
    return [
      new Plugin({
        key: autoNumberingPluginKey,
        state: {
          init(_, { doc }) {
            return computeNumbering(doc)
          },
          apply(tr, old) {
            return tr.docChanged ? computeNumbering(tr.doc) : old
          }
        },
        props: {
          decorations(state) {
            return this.getState(state)
          }
        }
      })
    ]
  }
})
```

**关键设计**：

- 使用 Decoration.widget，**不修改文档内容**
- 协同编辑时各客户端独立计算编号，不通过 Y.Doc 同步
- 加 debounce 优化大文档性能（在 `apply` 中判断 `docChanged`）
- CSS 类 `.auto-numbering` 控制编号样式

## 风险评估

| 风险                          | 措施                                                |
| ----------------------------- | --------------------------------------------------- |
| 替换 heading 可能影响现有文档 | GjbHeading 节点名仍为 `heading`，结构不变，无缝兼容 |
| AutoNumbering 大文档性能      | debounce + 仅在 docChanged 时重算                   |
| 协同编辑时编号不同步          | Decoration 各客户端独立计算，天然一致               |

## 验收标准

- 工具栏标题下拉支持 5 级
- H1-H5 自动绑定黑体和对应字号
- 多级编号自动生成（1, 1.1, 1.1.1 等）
- 增删标题后编号自动更新
- 协同编辑时各端编号一致
- 现有 H1-H3 文档打开正常
