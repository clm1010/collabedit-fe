# P0-1: 预设样式与模板库

> **优先级**: P0 | **预估工期**: 10天 | **前置依赖**: P0-0（字体/字号/段落格式基础）

## 目标

内置 GJB 438C 的 20+ 文档模板（SRS、SDD、STR 等），新建文档时自动套用正确的标题、正文、段落、表格样式。

## 现有可复用

- 后端 `Template` 模型（[schema.prisma](e:/job-project/collabedit-node-backend/prisma/schema.prisma) 311-333行）
- 前端 `src/api/template/index.ts` 模板 API

## 实现步骤

### Step 1: 后端 -- GjbTemplate 模型

修改 [prisma/schema.prisma](e:/job-project/collabedit-node-backend/prisma/schema.prisma)：

```prisma
model GjbTemplate {
  id          Int      @id @default(autoincrement())
  name        String   // "软件需求规格说明 SRS"
  code        String   @unique // "SRS"
  category    String   // "设计文档" / "测试文档" / "管理文档"
  description String?  @db.Text
  content     Json     // 完整 Tiptap HTML/JSON 内容
  outline     Json     // [{level:1, title:"引言"}, {level:2, title:"目的"}, ...]
  styles      Json     // {headingFont:"SimHei", bodyFont:"FangSong", bodySize:"14pt", ...}
  isBuiltin   Boolean  @default(true)
  isDeleted   Boolean  @default(false)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
}
```

### Step 2: 后端 -- API 接口

新增 `src/routes/gjbTemplate.ts`：

- `GET /api/gjbTemplate/list` -- 列表（支持 category 过滤）
- `GET /api/gjbTemplate/detail/:id` -- 详情（含完整 content）
- `POST /api/gjbTemplate/create` -- 新增（管理员）
- `PUT /api/gjbTemplate/update/:id` -- 更新（管理员）
- `DELETE /api/gjbTemplate/delete/:id` -- 软删除（管理员）

新增 `src/services/gjbTemplate.service.ts`：CRUD 逻辑。

修改 [src/main.ts](e:/job-project/collabedit-node-backend/src/main.ts)：注册路由。

### Step 3: 后端 -- 种子数据

修改 [src/seed.ts](e:/job-project/collabedit-node-backend/src/seed.ts)，预置 GJB 438C 标准模板：

- **设计文档**：SRS(软件需求规格说明)、SDD(软件设计说明)、SSDD(系统/子系统设计说明)、IRS(接口需求规格说明)、IDD(接口设计说明)
- **测试文档**：STP(软件测试计划)、STD(软件测试说明)、STR(软件测试报告)、SVVP(软件验证与确认计划)
- **管理文档**：SDP(软件开发计划)、SPS(软件产品规格说明)、SCMP(软件配置管理计划)、SQP(软件质量保证计划)、SPM(软件程序员手册)、CSOM(计算机系统操作员手册)、CRISD(计算机资源综合支持文件)、SVP(软件版本说明)、SPP(软件过程改进计划)

每个模板的 `content` 字段包含完整大纲结构（标题 + 占位说明文字），`styles` 字段包含：

```json
{
  "headingFont": "SimHei",
  "bodyFont": "FangSong",
  "bodySize": "14pt",
  "lineHeight": "28pt",
  "firstLineIndent": "2em",
  "pageSize": "A4"
}
```

### Step 4: 前端 -- API 调用

在 `src/api/template/index.ts` 或新增 `src/api/gjbTemplate/index.ts`：

```typescript
export const getGjbTemplateList = (params?: { category?: string }) =>
  request.get('/api/gjbTemplate/list', { params })

export const getGjbTemplateDetail = (id: number) => request.get(`/api/gjbTemplate/detail/${id}`)
```

### Step 5: 前端 -- 模板选择器组件

新增 `src/views/template/templateLibrary/TemplateSelector.vue`：

- Element Plus Dialog 弹窗
- 顶部 Tabs 按分类切换（设计文档 / 测试文档 / 管理文档 / 全部）
- 搜索输入框
- 卡片网格展示模板：图标 + 代号 + 名称 + 简要描述
- 点击卡片选择 → 确认后回调父组件

新增 `src/views/template/templateLibrary/GJB438CTemplates.ts`：

- 前端模板数据定义（用于离线场景或快速预览）
- TypeScript 类型定义

### Step 6: 前端 -- 集成到编辑器

修改 [MarkdownCollaborativeEditor.vue](e:/job-project/collabedit-fe/src/views/template/editor/MarkdownCollaborativeEditor.vue)：

- 在 `handleEditorReady` 回调中检测 Y.Doc 是否为空
- 若为空（新建文档），弹出 TemplateSelector
- 用户选择模板后：
  1. 从后端获取模板详情
  2. `editor.commands.setContent(template.content)` 写入内容
  3. 根据 `template.styles` 设置段落默认格式（通过 ParagraphFormat 扩展）

### Step 7: 正文默认样式应用

模板写入后自动应用 GJB 438C 正文默认样式：

- 遍历文档中所有 paragraph 节点
- 设置 `fontFamily: "FangSong"`, `fontSize: "14pt"`, `lineHeight: "28pt"`, `firstLineIndent: "2em"`
- 通过 Tiptap chain commands 批量设置

## 风险评估

| 风险                                  | 措施                                             |
| ------------------------------------- | ------------------------------------------------ |
| 模板内容写入可能与 Y.Doc 现有数据冲突 | 仅在 Y.Doc 为空时弹出选择器                      |
| 大量模板内容数据                      | 列表接口只返回元数据，详情按需加载               |
| 协同场景多人同时新建                  | 第一个写入的人设置内容，其他人通过 Y.js 同步获得 |

## 验收标准

- 新建模板文档时弹出模板选择器
- 可按分类浏览和搜索 GJB 438C 模板
- 选择模板后自动填充大纲结构和默认样式
- 正文自动应用仿宋四号 + 28磅行距 + 2字符首行缩进
- 已有文档打开不受影响（不弹选择器）
