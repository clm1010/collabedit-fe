## 二、已修复问题列表（16 项）

1. **导入表格列宽丢失** — 解析 OOXML 时提取 `w:gridCol` 写入 colgroup col width
2. **表格溢出编辑器右侧** — `clampColWidthsToBody` 按正文区等比缩放；`table-layout: fixed`
3. **合并单元格 colspan/rowspan 丢失** — `normalizeTableStructureForRender` 行补齐算法
4. **导入后表格背景色丢失** — 保留 `background-color` 声明，不被 `cleanWordHtml` 清除
5. **列宽拖拽后表格溢出** — `tableWidthSyncPlugin` 实时补偿；`cellMinWidth=10` 防极端值
6. **空单元格导致缺块** — 行补齐：检测 rowspan 占位后补齐 `<td><p></p></td>`
7. **colgroup col 数量与实际列数不一致** — `normalizeTableStructureForRender` pass3 规范 colgroup
8. **表格气泡菜单定位异常** — TableBubbleMenu 优化定位逻辑
9. **斜体文字在表格内渲染错位** — 修复 `font-style: italic` 与 `table-layout: fixed` 的交互
10. **小列宽单元格无法点击** — `cellMinWidth=10` 保障最小可交互宽度
11. **表格行高无法拖拽** — 新增 `rowResizing.ts` 插件
12. **表格手柄交互** — 新增 `tableHandles.ts` 插件
13. **导入后 pt 单位未转 px** — `preprocessHtmlForTiptap` 统一 pt→px
14. **OOXML 增强解析与 DocModel 评分选优** — `getTableContentScore` 对比两种解析结果
15. **导入红头文件表格样式丢失** — `parseRedHeadDocument` 路径保留表格样式
16. **新建表格自动铺满编辑器宽度** — `autoFitPluginKey` 插件

## 三、当前架构设计要点

| 要点                               | 说明                                                       |
| ---------------------------------- | ---------------------------------------------------------- |
| `cellMinWidth=10`                  | CustomTable 扩展设置，防止列宽过小导致无法交互             |
| `tableWidthSyncPlugin`             | ProseMirror 插件，拖拽列宽后实时同步总宽到 `<table>` style |
| `clampColWidthsToBody`             | 导入/预加载时将列宽总和缩放至正文区宽度，防溢出            |
| `table-layout: fixed`              | `cleanWordHtml` 统一设置，确保列宽精确生效                 |
| `parsePx` 增强                     | 支持 pt/cm/mm/in → px 转换，兼容 Word 各种单位             |
| `normalizeTableStructureForImport` | 入口归一化函数：colgroup 规范 + 列宽缩放 + 标记属性        |
| `normalizeTableStructureForRender` | 渲染前归一化：行补齐 + colgroup 数量修正                   |
| `resolveEditorTableBodyWidth`      | 从编辑器 DOM 计算正文区可用宽度（考虑 padding）            |
| DocModel vs OOXML 评分             | `getTableContentScore` 统计非空单元格数，取高分结果        |
