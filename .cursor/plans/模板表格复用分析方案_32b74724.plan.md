# 模板管理复用演训方案表格功能分析与实施方案

## 一、两套编辑器表格实现对比

### 演训方案编辑器（training）


| 组件                           | 复杂度 | 用途                                                                                     |
| ---------------------------- | --- | -------------------------------------------------------------------------------------- |
| `CustomTable.ts` (356行)      | 高   | tableWidth、fitTableToWidth、tableWidthSyncPlugin、autoFitPlugin、colwidth、cellMinWidth=10 |
| `CustomTableView.ts`         | 高   | 右下角缩放把手、列宽/行高 DOM 写回                                                                   |
| `CustomTableRow.ts`          | 中   | height 属性（行高拖拽）                                                                        |
| `CustomTableCell.ts`         | 中   | textAlign、backgroundColor、verticalAlign                                                |
| `CustomTableHeader.ts`       | 中   | 同 Cell                                                                                 |
| `tableHandles.ts`            | 高   | 悬浮行列选择条、快捷插入行列                                                                         |
| `rowResizing.ts`             | 高   | 行高拖拽插件                                                                                 |
| `tableStructureNormalize.ts` | 高   | Word 导入列宽归一化、colgroup 规范                                                               |
| `TableBubbleMenu.vue`        | 中   | 右键气泡菜单：行列操作、对齐、背景色、适应宽度                                                                |
| `TableToolbar.vue`           | 中   | 顶部工具栏表格操作面板                                                                            |


### 模板管理编辑器（template）


| 组件                          | 复杂度 | 用途                         |
| --------------------------- | --- | -------------------------- |
| `CustomTable.ts` (25行)      | 低   | 仅 style 属性（红头文件无边框表格）      |
| `CustomTableRow.ts` (19行)   | 低   | 仅 style 属性                 |
| `CustomTableCell.ts` (19行)  | 低   | 仅 style 属性                 |
| 无 TableBubbleMenu           | -   | 无气泡菜单                      |
| 工具栏内联在 `MarkdownEditor.vue` | 低   | insertTable、行列增删、合并拆分、删除表格 |


## 二、核心矛盾：Markdown 格式的表达能力限制

标准 GFM Markdown 表格**不支持**：

- colspan / rowspan（合并单元格）
- 列宽 / 行高
- 单元格背景色
- 单元格垂直对齐
- 单元格级别的文字对齐（仅支持列级 `:---`, `:---:`, `---:`）

这意味着：即使在编辑器中能用演训方案的全部表格功能，**保存为 Markdown 时这些高级特性全部丢失**。

## 三、当前致命问题

[htmlToMarkdown.ts](src/views/template/editor/utils/converters/htmlToMarkdown.ts) 第 138 行：

```
.replace(/<(?!___)[^>]+>/g, '')
```

这行正则会**清除所有未被前面规则匹配的 HTML 标签**，包括 `<table>`、`<tr>`、`<td>` 等，导致表格内容在保存时被打散为纯文本或丢失。

## 四、推荐方案：HTML 内嵌 + 分层复用

### 策略选择

考虑到模板管理的实际需求（合并单元格、背景色等在文档模板中是常见需求），**建议采用"HTML 块内嵌"策略**：在 Markdown 文件中直接保留 `<table>` HTML 块。理由：

1. `markdown-it` 已配置 `html: true`，加载时天然支持 HTML 块
2. 不丢失任何表格样式信息
3. 与 Tiptap 编辑器的 HTML 内部表示天然兼容
4. 这是业界常见做法（GitHub、Notion 导出的 Markdown 中都有 HTML 表格）

### 4.1 修复 htmlToMarkdown.ts（必须）

在 [htmlToMarkdown.ts](src/views/template/editor/utils/converters/htmlToMarkdown.ts) 的 `convertContentToMarkdown` 中，在正则链**最前面**添加表格保护逻辑：将 `<table>...</table>` 整块提取为占位符，保存时原样保留 HTML。

### 4.2 修复 markdownToHtml.ts（必须）

在 [markdownToHtml.ts](src/views/template/editor/utils/converters/markdownToHtml.ts) 的 `convertMarkdownContent` 中，添加 `<table>` HTML 块的识别与原样透传逻辑，确保列表页预览能正确渲染表格。

### 4.3 可安全复用的组件

以下演训方案组件可复用到模板管理，**不会产生负面影响**：

**a) `TableBubbleMenu.vue` -> 提取为共享组件**

- 路径：提取到 `src/shared/extensions/TableBubbleMenu.vue`（或直接引用演训方案的）
- 改造：通过 props 控制功能开关（如 `showFitToWidth`、`showCellBg`、`showVerticalAlign`）
- 在 [MarkdownEditor.vue](src/views/template/editor/components/MarkdownEditor.vue) 中挂载

**b) `CustomTableCell.ts` / `CustomTableHeader.ts` 的属性增强**

- 将模板编辑器的 `CustomTableCell.ts` 从仅支持 `style` 升级为支持 `textAlign`、`backgroundColor`、`verticalAlign`
- 参照演训方案的 [CustomTableCell.ts](src/views/training/document/components/toolbar/extensions/CustomTableCell.ts) 实现
- 这些属性在 HTML 内嵌保存策略下**不会丢失**

### 4.4 按需引入的组件（视需求决定）

**a) `tableHandles.ts`（行列悬浮选择条）**

- 提升交互体验，用户悬浮表格时显示快捷行列操作
- 但依赖 `.custom-table-view` CSS 选择器，需要同时引入 `CustomTableView`
- 如果引入，模板 `CustomTable` 需要配置 `View: CustomTableView`

**b) `rowResizing.ts`（行高拖拽）**

- 需要同时引入 `CustomTableRow` 的 `height` 属性
- 行高信息在 HTML 内嵌策略下可保留

### 4.5 不建议复用的组件


| 组件                            | 原因                                                                                                   |
| ----------------------------- | ---------------------------------------------------------------------------------------------------- |
| `CustomTable.ts` (training 版) | 整个 tableWidth 体系（tableWidthSyncPlugin、autoFitPlugin、fitTableToWidth 命令）是为 DOCX 精确列宽设计的，模板编辑器不需要这套复杂度 |
| `CustomTableView.ts`          | 右下角缩放把手和像素级列宽控制是 DOCX 场景，在 Markdown 模板中意义不大                                                          |
| `tableStructureNormalize.ts`  | 专为 Word 导入的 colgroup/列宽归一化设计，模板不涉及 Word 导入                                                           |
| `TableToolbar.vue`            | 模板编辑器已有内联工具栏，UI 风格不同，且 TableToolbar 依赖 `EditorKey` inject 和演训编辑器的组件体系                                |


## 五、影响分析

### 无影响（安全）

- 修改 `htmlToMarkdown.ts` / `markdownToHtml.ts` 只影响模板管理模块
- 增强 `CustomTableCell` 属性向后兼容
- 添加 `TableBubbleMenu` 是纯增量

### 需注意

- HTML 内嵌策略会使 `.md` 文件中出现 HTML 片段，如果有外部系统消费这些 md 文件需确认兼容性
- `@tiptap/markdown` 扩展（已注册）可能与自定义 `htmlToMarkdown` 有冲突，需验证是否 `editor.storage.markdown.getMarkdown()` 方法也能正确处理表格（如果能，可考虑替代自定义转换器）

## 六、实施步骤

按优先级排序：

1. **修复表格往返丢失**：`htmlToMarkdown.ts` 添加 `<table>` 保护、`markdownToHtml.ts` 添加 HTML 表格透传
2. **增强 CustomTableCell/CustomTableHeader**：添加 textAlign、backgroundColor、verticalAlign 属性
3. **引入 TableBubbleMenu**：提取为可配置的共享组件，挂载到 MarkdownEditor
4. **（可选）引入 tableHandles**：提升悬浮交互体验
5. **（可选）引入 rowResizing**：支持行高拖拽
