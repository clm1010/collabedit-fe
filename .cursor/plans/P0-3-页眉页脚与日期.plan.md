# P0-3: 页眉/页脚与日期

> **优先级**: P0 | **预估工期**: 5天 | **前置依赖**: P0-0, P0-6（DOCX导出）

## 目标

页眉自动插入文档标识和密级，页脚"第X页/共Y页"，日期格式 YYYY-MM-DD。

## 可行性关键问题

Tiptap/ProseMirror 是连续滚动编辑器，**没有分页概念**。"第X页/共Y页"只在打印/导出时才有意义。

**设计方案**：编辑态 = Vue 预览条（编辑器上方固定区域）；导出态 = Word 真实页眉页脚。

## 实现步骤

### Step 1: 后端 -- 密级字典

修改 [src/seed.ts](e:/job-project/collabedit-node-backend/src/seed.ts)：

通过现有 `DictType/DictItem` 模型新增：
- DictType: `{ dictType: "security_level", dictName: "密级" }`
- DictItem: 公开、内部公开、秘密、机密、绝密

### Step 2: 前端 -- HeaderFooterEditor 组件

新增 `src/views/template/editor/components/HeaderFooterEditor.vue`：

- Element Plus Dialog 弹窗
- 表单字段：
  - 文档标识（文本输入，如 "XXX-2026-001"）
  - 密级选择（el-select，从字典 API 获取）
  - 日期格式（el-select：YYYY-MM-DD / YYYY年MM月DD日）
  - 日期自动更新（checkbox）
  - 页脚格式（el-select："第X页/共Y页" / "第X页" / 无）
- 点击确认后将数据写入 `ydoc.getMap('documentMeta')`：
  ```typescript
  const meta = ydoc.getMap('documentMeta')
  meta.set('documentId', '...')
  meta.set('securityLevel', '...')
  meta.set('dateFormat', 'YYYY-MM-DD')
  meta.set('autoUpdateDate', true)
  meta.set('pageFooterFormat', '第X页/共Y页')
  ```

### Step 3: 前端 -- 编辑区预览条

在 [MarkdownEditor.vue](e:/job-project/collabedit-fe/src/views/template/editor/components/MarkdownEditor.vue) 的 `.editor-content-wrapper` 上方添加页眉预览区域：

```html
<div v-if="hasHeaderFooter" class="header-footer-preview" @click="openHeaderFooterEditor">
  <div class="header-preview">
    <span class="header-doc-id">{{ documentMeta.documentId || '点击设置文档标识' }}</span>
    <span class="header-security">{{ documentMeta.securityLevel || '' }}</span>
    <span class="header-date">{{ formattedDate }}</span>
  </div>
  <div class="footer-preview">
    <span>{{ documentMeta.pageFooterFormat || '' }}</span>
  </div>
</div>
```

- 通过 `ydoc.getMap('documentMeta').observe()` 监听变化
- 日期使用 dayjs 格式化，`autoUpdateDate` 为 true 时使用当前日期
- 点击预览条弹出 HeaderFooterEditor

### Step 4: 前端 -- 修改 MarkdownCollaborativeEditor

在 [MarkdownCollaborativeEditor.vue](e:/job-project/collabedit-fe/src/views/template/editor/MarkdownCollaborativeEditor.vue) 中：

- 将 `ydoc` 传给 MarkdownEditor（已传），MarkdownEditor 内部通过 `props.ydoc.getMap('documentMeta')` 获取元数据
- 工具栏新增"页面设置"按钮 → 弹出 HeaderFooterEditor

### Step 5: 导出适配（依赖 P0-6）

在 Word 导出逻辑（`wordExport.ts`）中：

```typescript
import { Header, Footer, Paragraph, TextRun, PageNumber, NumberOfPages } from 'docx'

// 读取 Y.Map 元数据
const meta = ydoc.getMap('documentMeta')

const header = new Header({
  children: [
    new Paragraph({
      children: [
        new TextRun(meta.get('documentId') || ''),
        new TextRun({ text: '\t' }),
        new TextRun(meta.get('securityLevel') || ''),
        new TextRun({ text: '\t' }),
        new TextRun(formattedDate),
      ]
    })
  ]
})

const footer = new Footer({
  children: [
    new Paragraph({
      alignment: 'center',
      children: [
        new TextRun('第'),
        new PageNumber(),
        new TextRun('页/共'),
        new NumberOfPages(),
        new TextRun('页'),
      ]
    })
  ]
})
```

### Step 6: 打印 CSS

在 MarkdownEditor.vue 的 style 中添加：

### Step 7: Markdown 兼容

导出 Markdown 时，在文件头部添加 YAML Front Matter：


导入 Markdown 时解析 Front Matter 恢复到 Y.Map。

## 风险评估

| 风险 | 措施 |
|------|------|
| Y.Map('documentMeta') 不存在时 | `ydoc.getMap()` 返回空 Map，不报错 |
| 页眉预览条影响编辑区滚动 | 使用 `position: sticky` 固定在顶部 |
| "第X页/共Y页" 编辑态无法显示真实页码 | 预览条显示占位文本，仅导出时渲染真实页码 |
