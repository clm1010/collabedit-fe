# P1-4: 批注与修订

> **优先级**: P1 | **预估工期**: 12天 | **前置依赖**: P0-0, P0-6（Word导出兼容）

## 目标

完全兼容 Word 的批注和修订功能，支持在线协同审阅、接受/拒绝修订。

**复杂度**：本方案是所有功能中复杂度最高的，TrackChanges 需要拦截 ProseMirror Transaction。

## 实现步骤

### Step 1: Comment 扩展（批注）

新增 `src/shared/extensions/Comment.ts`：
- Mark 类型，在文本上高亮标记
- 属性：`commentId`（关联到 Y.Array 中的完整数据）
- 高亮颜色：浅黄色背景 `background-color: rgba(255, 212, 0, 0.3)`
- 批注数据存储在 `ydoc.getArray('comments')`，每条数据结构：
  ```json
  { "id": "uuid", "content": "建议修改...", "userId": 1, "userName": "张三",
    "createdAt": "2026-03-12T10:00:00Z", "resolved": false, "replies": [...] }
  ```

### Step 2: TrackChanges 扩展（修订追踪）

新增 `src/shared/extensions/TrackChanges.ts`：
- 两个 Mark 类型：`insertion`（绿色下划线）和 `deletion`（红色删除线）
- ProseMirror Plugin 拦截 Transaction：
  - 开启追踪模式后，插入文本 → 自动添加 `insertion` mark
  - 删除文本 → 不真正删除，添加 `deletion` mark 并隐藏
  - 格式变更 → 记录变更前后差异
- 属性：`changeId`, `userId`, `userName`, `changeType`, `createdAt`
- 命令：`acceptChange(changeId)`, `rejectChange(changeId)`, `acceptAllChanges()`, `rejectAllChanges()`
- 修订数据存储在 `ydoc.getMap('trackChanges')`

### Step 3: CommentPanel 组件

新增 `src/views/template/editor/components/CommentPanel.vue`：
- 右侧面板（或在 CollaborationPanel 中新增 tab）
- 批注列表：用户头像+名称+时间+内容
- 回复功能
- 解决/取消解决
- 删除（仅作者或管理员）
- 点击批注 → 高亮并跳转到对应文本

### Step 4: RevisionPanel 组件

新增 `src/views/template/editor/components/RevisionPanel.vue`：
- 修订列表：谁在什么时候插入/删除了什么
- 单条接受/拒绝
- 全部接受/全部拒绝
- 筛选：按用户、按时间

### Step 5: 工具栏 -- 审阅工具组

修改 MarkdownEditor.vue 工具栏新增审阅组：
```html
<button @click="addComment" title="添加批注"><Icon icon="mdi:comment-plus" /></button>
<button @click="toggleTrackChanges" :class="{active: trackChangesEnabled}" title="修订追踪">
  <Icon icon="mdi:file-document-edit" /></button>
<button @click="showCommentPanel = true" title="批注面板"><Icon icon="mdi:comment-text-multiple" /></button>
<button @click="showRevisionPanel = true" title="修订面板"><Icon icon="mdi:history" /></button>
```

### Step 6: 后端持久化

新增 Prisma 模型 `DocumentComment`：
```prisma
model DocumentComment {
  id          String   @id @default(uuid())
  documentId  String
  userId      Int
  userName    String
  content     String   @db.Text
  parentId    String?
  resolved    Boolean  @default(false)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
  isDeleted   Boolean  @default(false)
}
```

新增 API：CRUD + 解决/取消解决。主数据源为 Y.Array，后端做持久化备份。

### Step 7: Word 导入/导出兼容

- **导入**：mammoth 解析 .docx 时提取批注 → 转为 Comment mark
- **导出**：`docx` 库 `CommentRangeStart`/`CommentRangeEnd` + `InsertedTextRun`/`DeletedTextRun`
