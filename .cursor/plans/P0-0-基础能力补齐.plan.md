# P0-0: 模板编辑器基础能力补齐

> **优先级**: P0（最高）| **预估工期**: 7天 | **前置依赖**: 无

## 背景

模板编辑器（MarkdownEditor）与演训编辑器（TiptapEditor）功能差异显著。GJB 438C 适配的所有后续功能均依赖基础排版能力。本方案将演训编辑器已有的基础扩展移植到模板编辑器。

**原则**：从演训编辑器复用/移植已有扩展，不重复开发。公共扩展提取到共享目录 `src/shared/extensions/`。

## 现有能力对比

| 能力                | 模板编辑器           | 演训编辑器            | 本方案动作           |
| ------------------- | -------------------- | --------------------- | -------------------- |
| 字体选择            | 无                   | FontFamily 已有       | 移植                 |
| 字号选择            | 无                   | FontSize 已有         | 移植                 |
| 段落格式(行距/缩进) | 无                   | 行高已有              | 新增 ParagraphFormat |
| 图片调整            | 无                   | ResizableImage 已有   | 移植                 |
| 上下标              | 无                   | Superscript/Subscript | 移植                 |
| 分页符              | 无                   | PageBreak             | 移植                 |
| 查找替换            | 无                   | 已有                  | 移植                 |
| Underline           | 工具栏有按钮但未验证 | 已有                  | 验证/补注册          |

### Step 3: 段落格式扩展（新增）

新增 `src/shared/extensions/ParagraphFormat.ts`：

```typescript
import { Extension } from '@tiptap/core'

export const ParagraphFormat = Extension.create({
  name: 'paragraphFormat',
  addGlobalAttributes() {
    return [
      {
        types: ['paragraph'],
        attributes: {
          lineHeight: {
            default: null,
            parseHTML: (el) => el.style.lineHeight || null,
            renderHTML: (attrs) =>
              attrs.lineHeight ? { style: `line-height: ${attrs.lineHeight}` } : {}
          },
          firstLineIndent: {
            default: null,
            parseHTML: (el) => el.style.textIndent || null,
            renderHTML: (attrs) =>
              attrs.firstLineIndent ? { style: `text-indent: ${attrs.firstLineIndent}` } : {}
          },
          spaceBefore: { default: null /* 类似实现 */ },
          spaceAfter: { default: null /* 类似实现 */ }
        }
      }
    ]
  }
})
```

注册到 MarkdownEditor.vue 的 extensions 数组。

### Step 4: ResizableImage 移植

**源文件**：

- [ResizableImage.ts](e:/job-project/collabedit-fe/src/views/training/document/components/toolbar/extensions/ResizableImage.ts)
- `ResizableImageComponent.vue`（同目录）

**操作**：

1. 复制到 `src/shared/extensions/image/`
2. 修改 `ResizableImageComponent.vue` 中的路径引用
3. MarkdownEditor.vue 注册 `ResizableImage`（替代 StarterKit 内置 Image）

### Step 5: 其他扩展移植

- **Superscript / Subscript**：`import { Superscript } from '@tiptap/extension-superscript'`，直接注册
- **PageBreak**：从演训编辑器查找 PageBreak 扩展，注册到模板编辑器
- **查找替换**：查找演训编辑器中的查找替换实现，移植到模板编辑器
- **Underline 验证**：在浏览器中测试模板编辑器的下划线按钮是否工作正常。Tiptap 3.x StarterKit 默认包含 Underline，若不包含则显式注册 `@tiptap/extension-underline`

6. **段落格式**（新增：行距/首行缩进下拉）
7. 颜色组（已有）
8. 列表组（已有）
9. 其他（已有）
