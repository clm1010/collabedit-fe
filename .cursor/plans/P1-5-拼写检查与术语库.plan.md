# P1-5: 拼写检查与术语库

> **优先级**: P1 | **预估工期**: 7天 | **前置依赖**: P0-0

## 目标

内置军用术语词典，检查术语使用错误，确保一致性（如"软件"不误写为"软体"）。集成查找替换功能。

## 实现步骤

### Step 1: 术语数据

新增 `src/views/template/editor/data/militaryTerms.ts`：
```typescript
export interface TermRule {
  wrong: string        // 错误用法
  correct: string      // 正确用法
  category: string     // 分类：通用/军事/软件工程
}

export const termRules: TermRule[] = [
  { wrong: '软体', correct: '软件', category: '通用' },
  { wrong: '信息系统', correct: '信息化系统', category: '军事' },
  // ... 更多规则
]

export interface Abbreviation {
  term: string
  fullName: string
}

export const abbreviations: Abbreviation[] = [
  { term: 'GJB', fullName: '国家军用标准' },
  { term: 'SRS', fullName: '软件需求规格说明' },
  // ...
]
```

### Step 2: SpellCheck 扩展

新增 `src/shared/extensions/SpellCheck.ts`：
- ProseMirror Plugin + Decoration
- 遍历文档文本节点，基于术语规则检测错误
- 红色波浪下划线标记（`Decoration.inline` + CSS）
- debounce 300ms
- 右键菜单显示修正建议

### Step 3: TerminologyPanel 组件

新增 `src/views/template/editor/components/TerminologyPanel.vue`：
- 显示文档中发现的术语问题列表
- 一键替换单个/全部
- 添加自定义术语规则

### Step 4: 查找替换移植

从演训编辑器移植查找替换功能到模板编辑器。与术语库联动：可"查找所有不规范术语并替换"。

### Step 5: 后端术语管理

利用现有 `DictType/DictItem` 管理术语，新增字典类型 `military_terms`，提供 API。
