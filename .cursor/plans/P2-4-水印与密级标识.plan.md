# P2-4: 水印与密级标识

> **优先级**: P2 | **预估工期**: 4天 | **前置依赖**: P0-0

## 目标

全文叠加半透明水印（"内部公开"/"秘密"等），支持自定义文字/角度/透明度，导出 Word 时保留水印。

## 实现步骤

### Step 1: Watermark 扩展

新增 `src/shared/extensions/Watermark.ts`：
- ProseMirror Plugin 的 `decorations`，在编辑器顶层渲染 canvas 水印
- 使用 canvas 绘制重复文字，转为 dataURL 作为背景图
- 水印配置存储在 `ydoc.getMap('watermark')`：
  ```json
  { "text": "内部公开", "angle": -30, "opacity": 0.15, "color": "#999", "fontSize": 24 }
  ```
- 水印叠加在编辑内容之上，`pointer-events: none` 不影响编辑

### Step 2: WatermarkDialog 组件

新增 `src/views/template/editor/components/WatermarkDialog.vue`：
- 预设选项：内部公开、秘密、机密（el-radio-group）
- 自定义文字输入
- 角度滑块（-90° ~ 0°）
- 透明度滑块（0.05 ~ 0.3）
- 颜色选择器
- 字号选择
- 实时预览

### Step 3: 工具栏按钮

修改 MarkdownEditor.vue 工具栏新增"水印"按钮。

### Step 4: Word 导出适配（依赖 P0-6）

在 `wordExport.ts` 中读取 Y.Map('watermark')，通过 `docx` 库 Header 中添加 watermark shape：
```typescript
// docx 库暂不直接支持水印，可通过 HeaderFooter 中的 Shape 或自定义 XML 实现
```

### Step 5: 协同同步

水印配置通过 Y.Map 自动同步到所有客户端。
